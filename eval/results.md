## Caveats

- The gold set is a draft written from the source texts, not yet reviewed by a compliance expert (`eval/questions_review.md`).
- Prompt v2 and the scenario questions were developed while looking at these same questions, so the v2 numbers are optimistic; a held-out set is needed for an unbiased estimate.
- 69 questions: one question moves a percentage by 1.4-1.7 points overall and by 6-11 points in the unanswerable and scenario subsets. Small differences between rows are not significant.
- Faithfulness is judged by Qwen 2.5 7B, the same model family as the system under test.
- The `-baseline` rows (and rows with "Vector per language: off") ran before per-language vector search, the per-list reranker pool and the inline-citation fallback were added. All other rows use the current code.
- Generation runs at temperature 0, but GPU inference is not bit-for-bit deterministic: rerunning the same configuration moved citation hit by about 2 points.
- Known failures the current default still has: it answers two out-of-scope questions (SAMA's framework, unpaid overtime) by applying unrelated controls and articles, and search misses the gold source for two scenarios whose wording shares nothing with the regulation (a cloud host in Germany vs "transfer outside the Kingdom"; cybersecurity reporting lines). An LLM scope check and query rewrite were tried with Qwen 7B and dropped: they rejected valid ECC questions and invented article numbers.
- An English question now reaches Arabic-only text (ECC 2-7-3 has no English counterpart). Without the reranker it ranks first for `vd-03` and for a rephrased version; with the reranker on, the rephrased version ranks it 9th, outside the 5 sources the model sees.
- Prompt v1 ran before the output size limits (`maxItems`/`maxLength`, `num_predict`) were added.
